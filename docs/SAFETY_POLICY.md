# 안전 정책

WinDirCleaner는 저장소를 **읽고 집계만** 합니다. **정리 실행·자동 삭제**는 없으며, **삭제를 수행하는 dry-run**도 없습니다.

일반 상세 분석과 NTFS 실험 메뉴는 모두 **읽기 전용** 범위를 지킵니다. NTFS 진단은 기본 분석을 대체하지 않으며, 앱 화면에서도 일반 분석 영역과 구분되어 있습니다.

**데모 모드**(앱 UI의 체크박스)는 정적 샘플 데이터만 표시하며, `DriveInfo`·디렉터리 열거·NTFS 진단 서비스 등 **파일 시스템에 접근하지 않습니다.** 정리 후보 새로고침·**정리 미리보기**도 실제 경로를 읽지 않고 샘플만 보여 줍니다. GitHub·포트폴리오 등 **공개 스크린샷에는 데모 모드 사용을 권장**합니다.

- 파일을 생성·수정·이동·삭제하지 않습니다.
- 드라이브 목록은 `System.IO.DriveInfo`로 읽습니다.
- 상세 분석은 이름, 크기, 파일 수, 폴더 수를 집계합니다.
- 접근할 수 없는 항목은 건너뜁니다.
- 심볼릭 링크, 정션, 재분석 지점은 따라가지 않습니다(루프 방지).
- 백그라운드 상주나 시작 프로그램 등록을 하지 않습니다.
- 네트워크 통신이나 텔레메트리는 없습니다.

## 정리 후보 미리보기(현재 단계)

화면의 **정리 후보 미리보기**는 **표시·분류·읽기 전용 크기 확인**까지를 포함합니다. 실제 디스크를 스캔해 “지울 수 있다”고 판정하지 않으며, **삭제·이동·휴지통 비우기·캐시 정리 실행**도 하지 않습니다.

### 읽기 전용 후보 탐지

- **후보 새로고침**은 파일을 **생성·수정·삭제하지 않습니다.** 허용된 일부 폴더에 대해 `Directory` / `FileInfo` 순회로 **크기만** 합산합니다.
- 접근할 수 없는 항목은 건너뜁니다. **재분석 지점(reparse point)·정션·심볼릭 링크**는 따라가지 않습니다.
- **위험(Dangerous) 후보**(WinSxS, DriverStore, Program Files 등)는 **크기를 계산하지 않으며**, UI에는 **보호됨**으로 표시합니다(큰 용량으로 오해를 줄이기 위함).
- 데모 모드가 켜져 있으면 후보 새로고침으로 **실제 파일 시스템 탐지를 실행하지 않으며**, 정적 샘플만 유지합니다.

### 정리 미리보기(읽기 전용)

- **정리 미리보기**는 선택한 **권장·선택** 후보에 대해, 실제로 정리 대상이 될 **수 있는** 파일을 **삭제 없이** 열거·크기 합산해 **요약과 샘플 일부**만 보여 줍니다.
- **위험(Dangerous) 분류** 항목은 미리보기에서도 **대상에 넣지 않습니다.** `Selectable=false` 또는 `CanDelete=false`인 항목도 대상에서 제외합니다.
- 접근할 수 없는 파일·폴더는 건너뛰며, **재분석 지점(reparse point)·정션·심볼릭 링크**는 따라가지 않습니다.
- 결과는 **집계·표시용**이며, “삭제가 완료되었습니다”처럼 읽히는 표현을 쓰지 않습니다. **삭제 실행 버튼이나 정리 실행은 없습니다.**

### NTFS 경로 매핑 진단(실험)

- **경로 매핑 진단**은 USN으로 읽은 FRN 맵에서 **선택한 정리 후보 경로**가 일치하는지 확인하는 **읽기 전용 실험**입니다. IOCTL로 메타데이터만 읽으며, 파일을 삭제·이동·권한 변경하지 않습니다.
- 이 결과는 후보 크기·정리 미리보기 숫자에 **자동 반영되지 않습니다.** 실패하거나 스킵되어도 **Directory 기반** 후보 기능은 그대로 사용할 수 있습니다.

### 분류(참고)

| 분류 | 의미 | 앱 동작 |
|------|------|---------|
| **권장(Recommended)** | 일반적으로 정리 후보가 될 **수 있는** 범주로 설명할 수 있는 위치 | 체크는 가능하지만 **삭제는 수행하지 않음** |
| **선택(Optional)** | 사용자 판단이 필요한 항목 | 체크는 가능하지만 **삭제는 수행하지 않음** |
| **위험(Dangerous)** | 시스템·프로그램 본체 등 직접 건드리면 손상 위험이 큰 위치 | **보호됨**: 체크 불가, 선택 불가 정책 값(`Selectable=false`, `CanDelete=false`) |

### 앞으로 실제 삭제를 검토한다면

별도 **삭제 확인·로그·실패·권한 처리** 설계를 거친 뒤에만 범위를 넓히는 것이 안전합니다. 현재 앱은 후보를 **보여 줄 뿐**이며, **CleanupItem을 삭제 파이프라인에 연결하지 않습니다.** 정리 미리보기도 **읽기 전용 집계**일 뿐입니다.

삭제 기능을 추가한다면 별도 화면, 미리보기, 사용자 확인 흐름을 두는 것이 좋습니다.
