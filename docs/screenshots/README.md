# 스크린샷

여기엔 README나 소개용으로 쓸 이미지를 두면 됩니다.

데모 모드를 켜 두고 찍으면 로컬 경로나 실제 파일 이름이 안 나와서 편합니다. 그래도 실제 드라이브 화면을 올릴 거면 이름·경로 정도는 한번 더 훑어 보는 게 좋고, NTFS 진단 결과에 파일 이름이 찍혀 있지 않은지도 같이 보면 됩니다. 창은 너무 작지 않게(대략 1366×768 이상, 여유 있으면 1440×900 근처) 잡아 두면 레이아웃이 덜 깨집니다.

PNG는 필요할 때만 넣으면 되고, 아직 없어도 됩니다. 맥락은 위쪽 [README.md](../../README.md)를 보면 됩니다.
